# Changelog

## 0.2.0 — Formal vocabulary and domain contracts

- Introduces a normative, implementation-independent specification for ontology, epistemology, axiology, praxeology and NTFS cognitive operations.
- Defines stable identity, scoped n-ary relationships, temporal records, typed propositions, evidence, claims, beliefs and revision provenance.
- Separates acquisition method, claim lifecycle, belief stance and confidence; distinguishes valuation, commitment, constraint and authority; separates action execution from observed outcomes.
- Introduces JSON exchange records, a self-contained garden fixture, and positive and negative conformance scenarios.
- Retains the four conceptual essays and marks the earlier Python sketch as historical and illustrative; revises the roadmap to formal dynamics (0.3) and reference implementation (0.4).
